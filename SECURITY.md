# Security

Please do not disclose a vulnerability in a public Issue, pull request, or
discussion. Use GitHub's private vulnerability reporting channel for
`luandemelo/codex-model-router` when it is enabled, or contact the repository
maintainer privately through the account's verified security contact.

Include a concise description, affected version or commit, reproduction steps,
impact, and a suggested mitigation. Redact credentials, personal data, and
private model output from the report. Do not run tests against another
person's account or external service without permission.

The maintainer will acknowledge a private report, reproduce it locally, agree
on a disclosure timeline, and credit the reporter when requested. Security
fixes should include a regression test and a changelog entry. External actions
such as issue creation, publication, release, or plugin installation remain
separately authorized.
